---
title: "Angular: Crear un proyecto"
sidebarTitle: "Creación de proyecto"
description: "Crear un proyecto Angular al vuelo con npx, usar una versión específica del CLI y levantar el servidor de desarrollo en localhost:4200."
---

## Sin el CLI instalado

```bash Terminal
npx @angular/cli@latest new nombre_proyecto
```

## Con una versión específica

```bash Terminal
npx @angular/cli@18.0 new nombre_proyecto
```

## Levantar el servidor

```bash Terminal
cd nombre_proyecto
npx ng serve
```

Por defecto queda en `http://localhost:4200`.
