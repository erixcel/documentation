Comando listo para levantar MySQL en local con Docker.

## Levantar MySQL

```bash Terminal
docker run -d \
  --name mysql \
  -e MYSQL_ROOT_PASSWORD=admin \
  -e MYSQL_DATABASE=testdb \
  -p 3306:3306 \
  mysql:8
```

## Conexión

```text
mysql://root:admin@127.0.0.1:3306/testdb
```

<Tip>Cambia la contraseña del root antes de usarlo en cualquier entorno real.</Tip>
