Comando listo para levantar PostgreSQL en local con Docker.

## Levantar PostgreSQL

```bash Terminal
docker run -d \
  --name postgres \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=admin \
  -e POSTGRES_DB=testdb \
  -p 5432:5432 \
  postgres:15
```

## Conexión

```text
postgresql://admin:admin@127.0.0.1:5432/testdb
```

<Tip>Cambia usuario, contraseña y base antes de usarlo en cualquier entorno real.</Tip>
