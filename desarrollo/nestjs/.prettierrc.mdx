sidebarTitle: "Prettier"
description: "Configuración de estilo de código con Prettier."
---

Guarda este contenido en el archivo `.prettierrc` de la raíz.

```json .prettierrc
{
  "singleQuote": true,
  "trailingComma": "all",
  "printWidth": 200,
  "tabWidth": 2,
  "semi": true
}
```
