---
title: "NestJS: Crear un proyecto"
sidebarTitle: "Creación de proyecto"
description: "Crear un proyecto NestJS al vuelo con npx, usar una versión específica del CLI y levantar el servidor de desarrollo en localhost:3000."
---

## Sin el CLI instalado

```bash Terminal
npx @nestjs/cli@latest new nombre_proyecto
```

## Con una versión específica

```bash Terminal
npx @nestjs/cli@10 new nombre_proyecto
```

## Levantar el servidor

```bash Terminal
cd nombre_proyecto
npm install
npm run start:dev
```

Por defecto queda en `http://localhost:3000`.
