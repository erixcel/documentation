## TraceFlow publicado en npm

Instala el **runtime** en dependencias normales:

```bash Terminal
npm install @erixcel/traceflow@^0.1.0
```

Los imports de código emplean `@erixcel/traceflow`:

```typescript
import { TraceNode } from '@erixcel/traceflow';
```

Evita el paquete sin namespace `traceflow` en los ejemplos nuevos.
