## Herramientas de TraceFlow

```bash Terminal
npm install --save-dev @erixcel/traceflow-kit@^0.1.1
```

Con la dependencia instalada, un script npm puede invocar el ejecutable local usando `traceflow-kit studio`. El ejemplo usa **oxlint**, Prettier y Jest, sin asumir ESLint o Passport como dependencias obligatorias.
