Este archivo es una **referencia de un backend concreto** y no un manifiesto universal. Conserva las versiones y scripts aportados para `luis-ormeno-backend`; adapta `name`, `description`, `postbuild` y las dependencias que no se utilicen. El script del Studio usa el ejecutable local de `@erixcel/traceflow-kit`.

    "start": "npm run start:prod",
    "start:dev": "node --watch -r ts-node/register -r tsconfig-paths/register src/main.ts",
    "start:debug": "node --inspect --watch -r ts-node/register -r tsconfig-paths/register src/main.ts",
    "start:prod": "node dist/main.js",
    "lint": "oxlint src/",

En un nuevo proyecto instala dependencias con `npm install` y registra `package-lock.json`. Evita instalar simultáneamente el antiguo paquete sin namespace `traceflow`.
