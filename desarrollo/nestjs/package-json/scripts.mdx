Scripts utilizados por el backend NestJS de referencia, con Node.js 24, TypeScript, Drizzle, Jest, oxlint y los paquetes publicados de TraceFlow. Ajusta rutas específicas de tu proyecto (en particular `postbuild`). Consulta el [package.json completo](/desarrollo/nestjs/package-json/ejemplo-completo).

```json package.json
{
  "scripts": {
    "build": "tsc -p tsconfig.build.json && tsc-alias -p tsconfig.build.json",
    "postbuild": "node -e \"require('node:fs').cpSync('src/modules/bettor/modules/auth/templates', 'dist/modules/bettor/modules/auth/templates', { recursive: true })\"",
    "start": "npm run start:prod",
    "start:dev": "node --watch -r ts-node/register -r tsconfig-paths/register src/main.ts",
    "start:debug": "node --inspect --watch -r ts-node/register -r tsconfig-paths/register src/main.ts",
    "start:prod": "node dist/main.js",
    "lint": "oxlint src/",
    "test": "node --experimental-vm-modules node_modules/jest/bin/jest.js --runInBand",
    "test:watch": "node --experimental-vm-modules node_modules/jest/bin/jest.js --watch",
    "test:cov": "node --experimental-vm-modules node_modules/jest/bin/jest.js --coverage --runInBand",
    "test:debug": "node --inspect-brk --experimental-vm-modules node_modules/jest/bin/jest.js --runInBand",
    "test:e2e": "node --experimental-vm-modules node_modules/jest/bin/jest.js --runInBand --testPathPatterns=api.e2e-spec",
    "format": "npm run format:all",
    "format:all": "prettier --write --ignore-path .gitignore .",
    "format:all:check": "prettier --check --ignore-path .gitignore .",
    "format:check": "npm run format:all:check",
    "db:create": "ts-node -r tsconfig-paths/register src/db/create.db.ts",
    "db:seed": "ts-node -r tsconfig-paths/register src/db/seed.db.ts",
    "db:reset": "ts-node -r tsconfig-paths/register src/db/reset.db.ts",
    "db:command": "ts-node -r tsconfig-paths/register src/db/command.db.ts",
    "db:migrate": "ts-node -r tsconfig-paths/register src/db/migrate.db.ts",
    "db:backup": "ts-node -r tsconfig-paths/register src/db/backup.db.ts",
    "db:restore": "ts-node -r tsconfig-paths/register src/db/restore.db.ts",
    "db:studio": "drizzle-kit studio",
    "traceflow:studio": "traceflow-kit studio",
    "generate:types": "ts-node -r tsconfig-paths/register scripts/generate-api-types.ts"
  }

```

## TraceFlow Studio

```bash Terminal
npm run traceflow:studio
```

El script `traceflow:studio` invoca `traceflow-kit studio` desde `node_modules/.bin` (lo resuelve npm automáticamente). No requiere `npm link` ni la descarga de un paquete `traceflow-kit` sin namespace.

## Precauciones

- `db:reset` y `db:restore` pueden modificar o borrar datos; necesitan autorización antes de ejecutarse.
- `postbuild` copia plantillas del módulo bettor/auth; solo es aplicable si esa carpeta existe.
- `generate:types` depende de `scripts/generate-api-types.ts`.
