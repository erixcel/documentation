sidebarTitle: "core"
description: "Configuraciones compartidas de arranque de una aplicación NestJS."
---

La carpeta `src/core` concentra configuraciones generales utilizadas durante la inicialización de NestJS.

Aquí encontrarás la configuración de **CORS**, la documentación **Swagger/OpenAPI**, las **transformaciones globales** y la **trazabilidad** de la aplicación.

Consulta cada página para revisar el código y los ajustes correspondientes antes de incorporarlos a tu proyecto.
