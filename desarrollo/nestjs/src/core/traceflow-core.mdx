Inicializa TraceFlow y registra el middleware HTTP para capturar trazas durante el **desarrollo local**. Se integra desde `src/main.ts` y envía las trazas al Studio configurado en `TRACEFLOW_STUDIO_URL`.

## Configuración

| Variable | Propósito |
| --- | --- |
| `TRACEFLOW_SERVICE_NAME` | Nombre que identifica el backend en el Studio; se usa en `setupTraceFlow(app)`. |
| `TRACEFLOW_STUDIO_URL` | Dirección local del Studio (por defecto `http://127.0.0.1:4789`). |
| `TRACEFLOW_ENABLED` | Habilita TraceFlow cuando es `true` y `PROD` no es `true`. |
| `TRACEFLOW_INSTRUMENT_HTTP` | Activa la instrumentación de HTTP. |
| `TRACEFLOW_DEBUG` | Activa los registros de depuración. |

## Archivo completo

Este archivo aplica la convención de `src/core`: **una sola función exportada** (`setupTraceFlow`) y un único parámetro `app: INestApplication`. La función también inicia TraceFlow antes de instalar el middleware; evita duplicar su inicialización en `main.ts`.

```typescript traceflow.core.ts
import type { INestApplication } from '@nestjs/common';
import { startTraceFlow, createTraceFlowHttpMiddleware } from '@erixcel/traceflow';

export function setupTraceFlow(app: INestApplication): void {
  // TraceFlow se utiliza únicamente en el entorno local de desarrollo.
  if (process.env.PROD === 'true' || process.env.TRACEFLOW_ENABLED?.toLowerCase() !== 'true') {
    return;
  }

  startTraceFlow({
    serviceName: process.env.TRACEFLOW_SERVICE_NAME || 'luis-ormeno-backend',
    studioUrl: process.env.TRACEFLOW_STUDIO_URL || 'http://127.0.0.1:4789',
    enabled: true,
    instrumentHttp: process.env.TRACEFLOW_INSTRUMENT_HTTP?.toLowerCase() === 'true',
    debug: process.env.TRACEFLOW_DEBUG?.toLowerCase() === 'true',
  });

  app.use(
    createTraceFlowHttpMiddleware({
      capture: {
        query: true,
        body: true,
        formData: true,
        cookies: true,
        authorization: 'full',
        headers: true,
      },
    }),
  );
}
```

**Importante:** esta configuración solo debe utilizarse en local. `authorization: 'full'`, `cookies: true` y `body: true` **pueden registrar tokens, credenciales o información sensible**. Utiliza únicamente datos de prueba; desactiva esas capturas si no las necesitas. El ejemplo también deshabilita el middleware cuando `PROD=true`.

## Instalación desde npm

TraceFlow se distribuye como paquetes publicados por Erixcel. **Ya no necesitas enlazar repositorios locales con `npm link`.**

```bash Terminal — backend NestJS
npm install @erixcel/traceflow@^0.1.0
npm install --save-dev @erixcel/traceflow-kit@^0.1.1
```

Para el Studio usa el ejecutable proporcionado por la dependencia de desarrollo:

```json package.json
"traceflow:studio": "traceflow-kit studio"
```

```bash Terminal
npm run traceflow:studio
```

Estas versiones corresponden a las indicadas en el `package.json` de referencia. El `package-lock.json` fija la versión efectiva al instalar. Revisa el contrato real del paquete antes de ajustar opciones de captura.

En `src/main.ts`, llama únicamente `setupTraceFlow(app)` después de crear la aplicación y antes de `app.listen()`. No llames a `startTraceFlow()` por segunda vez. Consulta [`main.ts`](/desarrollo/nestjs/src/main).
