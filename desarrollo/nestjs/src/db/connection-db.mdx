Configura un `Pool` de PostgreSQL y crea la conexión de **Drizzle ORM** registrando las tablas disponibles en el proyecto.

## Ejemplo general

```typescript connection.db.ts
import { drizzle } from 'drizzle-orm/node-postgres';
import { Pool } from 'pg';
import { dbConfig } from '@db/config.db';

import { user } from '@db/tables/user.table';
import { category } from '@db/tables/category.table';
import { product } from '@db/tables/product.table';

const pool = new Pool(dbConfig);

const schema = {
  user,
  category,
  product,
};

export const database = drizzle(pool, { schema });
```

**Adapta los imports y el objeto `schema` a las tablas que realmente tenga tu proyecto.** Estos tres nombres son solo ejemplos; no tienes que crear tablas innecesarias. Cada tabla debe estar definida en su archivo `.table.ts` correspondiente.
