La carpeta `src/db` organiza los archivos y las operaciones relacionadas con la base de datos del backend.

Esta documentación incluye **conexión y configuración**, definiciones de **tablas con Drizzle ORM**, **migraciones**, **semillas de datos (seeds)**, **comandos** y procesos de **respaldo y restauración**.

Abre la página correspondiente para consultar sus convenciones, implementaciones y comandos.
