# Tables de Drizzle ORM

En `src/db/tables/`, cada archivo `[nombre].table.ts` define **exactamente una tabla PostgreSQL** mediante `pgTable(...)` y, opcionalmente, sus enums `pgEnum(...)`.

## Declaraciones permitidas en un archivo `.table.ts`

Solo se permiten:

- **Imports** necesarios para definir el esquema.
- **Una tabla exportada:** `export const users = pgTable(...)`.
- **Enums Drizzle:** `const userRoleEnum = pgEnum(...)` o `export const userRoleEnum = pgEnum(...)`, según si otros archivos necesitan importarlos.

Quedan prohibidos otros `const`, `let` y `var`, así como declaraciones `type`, `interface`, `class`, `function`, `enum` de TypeScript y reexportaciones. Esto también impide crear un helper como `const timestamp = (...)` o `const pgTimestamp = (...)` para las columnas de auditoría. **No conviertas un helper en una clase ni añadas decoradores.**

Los tipos inferidos de Drizzle (`typeof users.$inferSelect`, `typeof users.$inferInsert`) siguen estando disponibles, pero deben utilizarse **fuera del `.table.ts`**, por ejemplo en los contratos/DTO o consumidores que realmente los necesitan. No declares `export type User = ...` ni `export interface User ...` dentro de la tabla.

## Tres campos de auditoría obligatorios

**Sin excepciones:** todas las tablas, incluidas las intermedias, declaran estas propiedades y columnas en inglés.

```typescript
createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
updatedAt: timestamp('updated_at', { withTimezone: true }).defaultNow().notNull(),
deletedAt: timestamp('deleted_at', { withTimezone: true }),
```

La opción `{ withTimezone: true }` es válida y puede incluirse directamente como segundo argumento; también es válido `timestamp('created_at')` sin opciones. **El validador acepta ambos formatos directos**, no aliases ni funciones auxiliares. Si empleas zonas horarias, sé consistente entre columnas.

| Campo | Significado |
| --- | --- |
| `createdAt` / `created_at` | Fecha y hora de creación |
| `updatedAt` / `updated_at` | Fecha y hora de última actualización |
| `deletedAt` / `deleted_at` | Borrado lógico, anulable |

`defaultNow()` únicamente inicializa `updatedAt`: la aplicación debe actualizarlo en modificaciones o configurar el mecanismo que lo haga.

## Ejemplo válido completo

```typescript user.table.ts
import {
  pgTable,
  pgEnum,
  serial,
  text,
  varchar,
  timestamp,
  index,
  uniqueIndex,
} from 'drizzle-orm/pg-core';
import { sql } from 'drizzle-orm';

// Permitido: enum Drizzle, exportado solo si se consume en otros archivos.
export const userRoleEnum = pgEnum('user_role', ['admin', 'employee', 'viewer']);

// Permitido: una tabla exportada.
export const user = pgTable(
  'user',
  {
    id: serial('id').primaryKey(),
    email: varchar('email', { length: 255 }).notNull(),
    password: text('password').notNull(),
    role: userRoleEnum('role').default('viewer').notNull(),
    createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).defaultNow().notNull(),
    deletedAt: timestamp('deleted_at', { withTimezone: true }),
  },
  (t) => [
    index('user_created_at_idx').on(t.createdAt),
    uniqueIndex('user_email_unique_active_idx')
      .on(t.email)
      .where(sql`${t.deletedAt} IS NULL`),
  ],
);
```

Los DTO pueden obtener valores del enum a través de `user.role.enumValues`, sin duplicar la lista de valores. Si el enum solo se usa en esta tabla, puede permanecer sin `export`. Un enum compartido por varias tablas requiere una decisión explícita de ubicación compartida, sin duplicarlo.

**Nota:** el índice GIN con `gin_trgm_ops`, si se utiliza, requiere activar la extensión PostgreSQL `pg_trgm`.

## Validación

El **Table Validator** comprueba las únicas declaraciones permitidas, la tabla principal exportada, el formato directo de los tres timestamps y sus modificadores obligatorios. Su análisis estático ignora comentarios y literales para identificar declaraciones; no ejecuta el esquema ni realiza migraciones. Las pruebas verifican casos válidos y prohibidos.
