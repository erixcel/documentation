La carpeta `src/functions` contiene funciones reutilizables que ayudan a mantener la lógica auxiliar fuera de los controladores y servicios cuando corresponde.

En esta sección se documentan utilidades para **fechas**, **cadenas de texto**, **errores de base de datos** y **paginación**.

Consulta las páginas para conocer los parámetros, tipos y ejemplos de implementación.
