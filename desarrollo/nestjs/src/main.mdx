Punto de entrada de NestJS. Carga las variables de entorno, inicializa TraceFlow **solo para desarrollo local**, crea la aplicación, registra las configuraciones globales e inicia el servidor.

Por convención, **cada archivo `src/core/*.core.ts` exporta únicamente una función `setupNombre(app: INestApplication)`**. La inicialización anticipada de TraceFlow se hace aquí para conservar el orden correcto de arranque sin agregar otra función a `traceflow.core.ts`.

```typescript main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { config } from 'dotenv';
import { startTraceFlow } from 'traceflow';
import { setupTraceFlow } from '@core/traceflow.core';
import { setupSwagger } from '@core/swagger.core';
import { setupTransform } from '@core/transform.core';
import { setupCors } from '@core/cors.core';

config();

async function bootstrap() {
  // Inicializa trazabilidad antes de crear la aplicación.
  startTraceFlow({
    serviceName: process.env.TRACEFLOW_SERVICE_NAME || 'nombre-backend',
    studioUrl: process.env.TRACEFLOW_STUDIO_URL || 'http://127.0.0.1:4789',
    enabled: process.env.TRACEFLOW_ENABLED?.toLowerCase() === 'true' && process.env.PROD !== 'true',
    instrumentHttp: process.env.TRACEFLOW_INSTRUMENT_HTTP?.toLowerCase() === 'true',
    debug: process.env.TRACEFLOW_DEBUG?.toLowerCase() === 'true',
  });

  const app = await NestFactory.create(AppModule);

  setupCors(app);
  setupTraceFlow(app);
  setupTransform(app);
  setupSwagger(app);

  await app.listen(process.env.PORT || 3000);
}

bootstrap();
```

`startTraceFlow(...)` utiliza `TRACEFLOW_ENABLED`, `TRACEFLOW_STUDIO_URL` y las demás variables del archivo `.env`. El arranque instrumental se realiza antes de crear la aplicación; `setupTraceFlow(app)` instala el middleware HTTP solo cuando TraceFlow está habilitado y `PROD` no es `true`.

Las demás funciones `setup...` se encuentran en `src/core` y se invocan con el único parámetro `app`. Consulta [`traceflow.core.ts`](/desarrollo/nestjs/src/core/traceflow-core) para la configuración del middleware y las recomendaciones de seguridad.

**Seguridad:** la captura de tokens, cookies o contenido de peticiones debe limitarse a entornos locales con datos de prueba.
