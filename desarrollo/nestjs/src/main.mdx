Punto de entrada de NestJS. Carga las variables de entorno, crea la aplicación, configura TraceFlow **solo en desarrollo local** junto con el resto de componentes globales e inicia el servidor.

Por convención, **cada archivo `src/core/*.core.ts` exporta únicamente una función `setupNombre(app: INestApplication)`**. La función `setupTraceFlow(app)` inicializa TraceFlow e instala el middleware en un solo lugar.

```typescript main.ts
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';
import { config } from 'dotenv';
import { setupTraceFlow } from '@core/traceflow.core';
import { setupSwagger } from '@core/swagger.core';
import { setupTransform } from '@core/transform.core';
import { setupCors } from '@core/cors.core';

config();

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  setupCors(app);
  setupTraceFlow(app);
  setupTransform(app);
  setupSwagger(app);

  await app.listen(process.env.PORT || 3000);
}

bootstrap();
```

`startTraceFlow(...)` utiliza `TRACEFLOW_ENABLED`, `TRACEFLOW_STUDIO_URL` y las demás variables del archivo `.env`. La inicialización y el middleware se ejecutan desde `setupTraceFlow(app)` cuando TraceFlow está habilitado y `PROD` no es `true`.

Las demás funciones `setup...` se encuentran en `src/core` y se invocan con el único parámetro `app`. Consulta [`traceflow.core.ts`](/desarrollo/nestjs/src/core/traceflow-core) para la configuración del middleware y las recomendaciones de seguridad.

**Seguridad:** la captura de tokens, cookies o contenido de peticiones debe limitarse a entornos locales con datos de prueba.
