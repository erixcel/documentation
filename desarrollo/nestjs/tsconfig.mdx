Archivo `tsconfig.json` de la raíz del proyecto.

```json tsconfig.json
{
  "compilerOptions": {
    "module": "nodenext",
    "moduleResolution": "nodenext",
    "resolvePackageJsonExports": true,
    "esModuleInterop": true,
    "isolatedModules": true,
    "declaration": true,
    "removeComments": true,
    "emitDecoratorMetadata": true,
    "experimentalDecorators": true,
    "allowSyntheticDefaultImports": true,
    "target": "ES2023",
    "types": ["node", "jest"],
    "sourceMap": true,
    "outDir": "./dist",
    "incremental": true,
    "skipLibCheck": true,
    "strict": true,
    "strictPropertyInitialization": false,
    "paths": {
      "@core/*": ["src/core/*"],
      "@models/*": ["src/models/*"],
      "@db/*": ["src/db/*"],
      "@seeds/*": ["src/seeds/*"],
      "@modules/*": ["src/modules/*"],
      "@controllers/*": ["src/controllers/*"],
      "@services/*": ["src/services/*"],
      "@queries/*": ["src/queries/*"],
      "@functions/*": ["src/functions/*"],
      "@utils/*": ["src/utils/*"],
      "@config/*": ["src/config/*"]
    }
  }
}
```

## Alias de rutas: `paths`

**La sección `paths` es especialmente importante:** permite importar módulos con alias como `@db/config.db` en lugar de rutas relativas largas. Añade estas rutas dentro de `compilerOptions` y adáptalas a las carpetas reales de tu proyecto.

```json tsconfig.json
"paths": {
  "@core/*": ["src/core/*"],
  "@models/*": ["src/models/*"],
  "@db/*": ["src/db/*"],
  "@seeds/*": ["src/seeds/*"],
  "@modules/*": ["src/modules/*"],
  "@controllers/*": ["src/controllers/*"],
  "@services/*": ["src/services/*"],
  "@queries/*": ["src/queries/*"],
  "@functions/*": ["src/functions/*"],
  "@utils/*": ["src/utils/*"],
  "@config/*": ["src/config/*"]
}
```

Ejemplo:

```typescript Ejemplo de importación
import { dbConfig } from '@db/config.db';
```

**Importante:** `paths` facilita la resolución de imports durante el análisis/compilación de TypeScript, pero no reescribe los imports emitidos en JavaScript. Configura la resolución de alias también en las herramientas de ejecución o compilación que lo necesiten.
