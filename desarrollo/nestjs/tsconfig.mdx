Ubicación dentro de `tsconfig.json`:

```jsonc tsconfig.json
{
  "compilerOptions": {
    "module": "nodenext",
    "moduleResolution": "nodenext",
    // ... otras opciones
    "strictPropertyInitialization": false,
    // Coloca aquí "paths"
  }
}
```

## Alias de rutas: `paths`

Copia este bloque dentro de `compilerOptions`, en el lugar señalado arriba:n alias como `@db/config.db` en lugar de rutas relativas largas. Añade estas rutas dentro de `compilerOptions` y adáptalas a las carpetas reales de tu proyecto.

```json tsconfig.json
"paths": {
  "@core/*": ["src/core/*"],
  "@models/*": ["src/models/*"],
  "@db/*": ["src/db/*"],
  "@seeds/*": ["src/seeds/*"],
  "@modules/*": ["src/modules/*"],
  "@controllers/*": ["src/controllers/*"],
  "@services/*": ["src/services/*"],
  "@queries/*": ["src/queries/*"],
  "@functions/*": ["src/functions/*"],
  "@utils/*": ["src/utils/*"],
  "@config/*": ["src/config/*"]
}
```

Ejemplo:

```typescript Ejemplo de importación
import { dbConfig } from '@db/config.db';
```

**Importante:** `paths` facilita la resolución de imports durante el análisis/compilación de TypeScript, pero no reescribe los imports emitidos en JavaScript. Configura la resolución de alias también en las herramientas de ejecución o compilación que lo necesiten.
