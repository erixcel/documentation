---
title: "React: Crear un proyecto"
sidebarTitle: "Creación de proyecto"
description: "Crear un proyecto React al vuelo con Vite, usar una plantilla o versión específica y levantar el servidor de desarrollo en localhost:5173."
---

## Sin el CLI instalado

```bash Terminal
npm create vite@latest nombre_proyecto -- --template react-ts
```

## Con una versión específica

```bash Terminal
npm create vite@5 nombre_proyecto -- --template react-ts
```

## Levantar el servidor

```bash Terminal
cd nombre_proyecto
npm install
npm run dev
```

Por defecto queda en `http://localhost:5173`.
