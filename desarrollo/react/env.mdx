# Variables de entorno

En el frontend, las variables con prefijo `VITE_` son accesibles **públicamente en el navegador**. Nunca incluyas contraseñas, llaves privadas ni tokens secretos en ellas.

```dotenv .env.example
VITE_API_URL=http://localhost:3000
```

Para el entorno local puedes definir `frontend/.env`, que debería estar excluido del control de versiones. Mantén documentados sus **nombres** en `.env.example`, pero nunca copies valores sensibles.

```tsx
const apiUrl = import.meta.env.VITE_API_URL;
```

**Env & Package Validator** comprueba que las claves de `.env` aparezcan en `.env.example`, que el archivo de ejemplo no contenga patrones evidentes de credenciales reales y que ninguna variable pública se nombre como un secreto.
