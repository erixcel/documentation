# package.json de referencia

Manifiesto de ejemplo basado en el frontend Erixcel. Los scripts y versiones son una **referencia actualizada del proyecto compartido**, no un bloqueo de versiones universales. Al cambiar dependencias, mantén actualizado `package-lock.json` y comprueba `npm run build`.

```json package.json
{
  "name": "frontend",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vite build",
    "lint": "eslint .",
    "preview": "vite preview",
    "test": "node --experimental-strip-types --test test/*.test.mjs"
  },
  "dependencies": {
    "@tailwindcss/vite": "^4.3.3",
    "libphonenumber-js": "^1.13.15",
    "lucide-react": "^1.49.0",
    "react": "^19.2.8",
    "react-dom": "^19.2.8",
    "react-international-phone": "^4.8.0",
    "react-router-dom": "^7.18.4",
    "tailwindcss": "^4.3.3"
  },
  "devDependencies": {
    "@eslint/js": "^10.0.1",
    "@types/node": "^24.13.3",
    "@types/react": "^19.2.18",
    "@types/react-dom": "^19.2.7",
    "@vitejs/plugin-react": "^6.1.1",
    "eslint": "^10.10.0",
    "eslint-plugin-react-hooks": "^7.1.1",
    "eslint-plugin-react-refresh": "^0.5.6",
    "globals": "^17.12.0",
    "typescript": "~6.0.2",
    "typescript-eslint": "^8.69.0",
    "vite": "^8.3.0"
  }
}
```

## Verificación

- `npm run dev`: servidor de desarrollo Vite.
- `npm run build`: compilación de referencias TypeScript y bundle Vite.
- `npm run lint`: ESLint.
- `npm run preview`: vista previa de build.
- `npm test`: pruebas con Node y strip types.

**Referencia flexible:** los scripts y las dependencias mostrados corresponden a este ejemplo de frontend; **Package Validator fue retirado** y el plugin no impondrá estos scripts ni paquetes a otros proyectos. `Env Validator` sigue revisando únicamente `.env` y `.env.example`, sin cambiar `package.json`.
