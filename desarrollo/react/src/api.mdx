# src/api

```text
src/api/
└── backend.api.ts
```

**Solo se permite `backend.api.ts`**, generado desde el contrato del backend. No se admiten subcarpetas ni archivos como `http.api.ts`. No edites manualmente el código generado; regenera el contrato.

Se **permiten** `type`, `interface` y `class` emitidos por el generador. La restricción de «solo funciones» de hooks y servicios no aplica aquí.

Los clientes configurados, manejo de sesiones, subida de archivos y operaciones de datos van en `services/`. La coordinación React va en `hooks/`.

**API Validator** comprueba estructura y presencia del archivo generado. El Hook no puede demostrar si una modificación del archivo fue una regeneración legítima, porque no se ha definido una huella de procedencia del generador.
