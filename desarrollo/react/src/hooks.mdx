# src/hooks y hooks privados

Todos los hooks personalizados, también los privados de páginas y componentes complejos, utilizan `*.hook.ts`:

```text
src/hooks/use-api-query.hook.ts
src/pages/auth/hooks/use-auth.hook.ts
src/components/complex/modal/hooks/modal.hook.ts
```

Las funciones que invocan hooks React se llaman `useNombre`; las auxiliares pueden tener nombres distintos. Los hooks gestionan estado, efectos, refs y coordinación React; deben limpiar listeners, temporizadores, grabaciones y suscripciones y cumplir las Rules of Hooks. Las operaciones de datos se delegan a servicios.

## Solo funciones en el nivel superior

Se permiten imports (`import type` incluido), declaraciones de funciones y `const` cuyo valor sea una función flecha o expresión de función. Puede haber varias funciones por archivo. Se permiten variables **dentro** de funciones y tipos inline, genéricos y parámetros tipados.

No se permiten `type`, `interface`, `class`, `enum`, `namespace`, objetos, constantes de datos, instancias, cachés, estados compartidos o efectos de inicialización a nivel superior.

```ts src/hooks/use-session.hook.ts
import { useMemo } from 'react';

export function useSession(session: { id: string } | null) {
  return useMemo(() => session !== null, [session]);
}

export const normalizeEmail = (email: string) =>
  email.trim().toLowerCase();
```

**React Hook Validator** usa el AST de TypeScript para comprobar extensiones y declaraciones sin confundir comentarios con código; el lint de React Hooks complementa la comprobación semántica.

La carpeta oficial de contratos y estado compartido **está pendiente de definir**. No pierdas tipado ni comportamiento al migrar código existente.
