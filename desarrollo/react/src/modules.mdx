# src/modules

Cada funcionalidad tiene su propia carpeta. No coloques páginas sueltas directamente en `src/modules/`.

```text
src/modules/
├── auth/
│   ├── components/
│   ├── hooks/
│   │   └── use-auth.hook.ts
│   ├── services/
│   │   └── auth-session.service.ts
│   ├── index.ts
│   └── auth.page.tsx
└── not-found/
    └── not-found.page.tsx
```

Cada módulo conserva sus componentes, hooks y servicios privados. Los archivos `*.hook.ts` y `*.service.ts` siguen las reglas del plugin incluso dentro de subcarpetas. Se permiten `index.ts` públicos de módulos (la prohibición de barrels aplica a componentes compartidos).

La página no encontrada pertenece a `src/modules/not-found/`. No apliques a React la convención NestJS `*.module.ts` ni reintroduzcas SEO/prerenderizado.

**Guía, no Hook obligatorio:** la organización de módulos es una convención recomendada. El validador automático Module & Route fue retirado para respetar las distintas arquitecturas de los proyectos.
