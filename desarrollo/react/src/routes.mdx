# src/routes

La carpeta `src/routes/` contiene **configuración de navegación**, no implementaciones de páginas. Es válido usar JSX en la declaración de los elementos de ruta.

```tsx src/routes/path.route.tsx
import { createBrowserRouter } from 'react-router-dom';
import { HomePage } from '../modules/home/home.page';

export const router = createBrowserRouter([
  { path: '/', element: <HomePage /> },
]);
```

El ejemplo es orientativo: utiliza los componentes y nombres reales de tu frontend. La página `not-found` se implementa en `src/modules/not-found/` y se referencia desde el router. Integra las rutas con `RouterProvider` desde `src/main.tsx`.

**Module & Route Validator** detecta implementaciones `*.page.tsx` / `*.screen.tsx` dentro de routes y comprueba que exista configuración de React Router.
