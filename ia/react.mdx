# Erixcel React

Plugin independiente de **Erixcel NestJS** que incluye **10 Skills y 9 Hooks** para proyectos React 19 + Vite 8 + TypeScript. La estructura del código se concentra en `frontend/src/`; en la raíz se revisan principalmente `package.json`, `.env` y `.env.example`.

## Cómo instalarlo y activarlo

<Steps>
  <Step title="Agregar marketplace">
    Abre **Codex Desktop → Settings → Plugins → Add → Add a marketplace** y pega en **Source**:

    ```text Marketplace Erixcel
    erixcel/documentation
    ```
  </Step>
  <Step title="Instalar Erixcel React">
    En **Erixcel Developer Tools**, instala el plugin **Erixcel React**. Es independiente de NestJS y puede activarse por separado.
  </Step>
  <Step title="Autorizar los Hooks">
    Abre **Codex Desktop → Settings → Hooks**, revisa los comandos, autorízalos con **Trust** y activa los interruptores deseados.
  </Step>
  <Step title="Probar una validación">
    Abre un proyecto React + Vite y solicita una modificación pequeña en `src/main.tsx`; al terminar, el evento **Stop** verificará las reglas pertinentes si **Detect Changes** está activo.
  </Step>
</Steps>

```text
frontend/
├── src/

│   ├── services/
│   ├── index.css
│   └── main.tsx
├── .env
├── .env.example
└── package.json
```

## Hooks por evento (9)

### Antes de comenzar

**UserPromptSubmit**: **Detect Changes** registra el estado de `src/` y de los archivos de configuración relevantes.

### Al terminar

**Stop**: ocho validadores independientes revisan estructura, main, componentes, hooks personalizados, rutas, módulos, API/servicios y package/env; solo reportan problemas si hubo cambios pertinentes. Las validaciones responden a Codex con feedback, pero no editan archivos directamente.

La lista de Skills y Hooks publicados está también en el [catálogo de Skills](/ia/skills) y [catálogo de Hooks](/ia/hooks), ambos generados desde el marketplace.
