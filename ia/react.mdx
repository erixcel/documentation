**Erixcel React** incluye **12 Skills y 9 Hooks** para frontends React + Vite. Es independiente del otro plugin: no instala sus Skills ni sus Hooks.

## Cómo instalarlo

<Steps>
  <Step title="Agregar el marketplace">
    Abre **Codex Desktop → Settings → Plugins → Add → Add a marketplace** y pega la fuente:

    ```text Marketplace de Erixcel
    erixcel/documentation
    ```
  </Step>
  <Step title="Instalar Erixcel React">
    Dentro de **Personal → Erixcel Developer Tools**, busca **Erixcel React** e instálalo. No es necesario instalar el otro plugin.
  </Step>
  <Step title="Comprobar las Skills">
    En **Codex Desktop → Customize → Plugins → Erixcel React**, revisa sus 12 Skills. Se distribuyen solo con este plugin.
  </Step>
  <Step title="Autorizar y activar los Hooks">
    En **Codex Desktop → Settings → Hooks**, abre **Erixcel React**, inspecciona los comandos y pulsa **Trust** para autorizar los que confíes. Activa **Detect Changes** y los validadores que quieras usar.
  </Step>
  <Step title="Probar el plugin">
    Abre un proyecto React + Vite y pide un cambio pequeño a `src/main.tsx`. Al finalizar el turno, los ocho Hooks de Stop activos pueden enviar feedback para autocorregir incumplimientos. Structure, Module & Route y Package son recomendaciones de documentación y no bloquean cambios.
  </Step>
</Steps>

## Documentación y sincronización

Consulta la [guía de estructura](/desarrollo/react/estructura), [variables de entorno](/desarrollo/react/env) y [package.json](/desarrollo/react/package-json). Solo se validan archivos de React + Vite; no se ejecutan validadores NestJS.

Las Skills y los Hooks se publican en GitHub. Las actualizaciones del plugin instalado se gestionan aparte en Codex Desktop; la publicación no significa que los Hooks estén activados localmente.

Consulta la [convención de stores](/desarrollo/react/src/stores) para gestionar instancias compartidas por alcance.
